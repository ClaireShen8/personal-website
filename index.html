Project In progress

HouseMeds

Web tool · Prescription price search

A web tool that searches pre-vetted pharmacies for the cheapest way an entire household — pets included — can fill its prescriptions each month.

[Role] · [Dates] · [Stack]

The Problem

Purchasing prescription medications is an expensive, time-consuming process for many Americans. In many cases, paying out of pocket rather than going through insurance is the easier and more affordable route — but finding out whether that's true for a given prescription means checking site after site, one drug at a time.

What I Built

A web tool that searches pre-vetted pharmacy websites for the most affordable way for an entire household, pets included, to fill its prescriptions each month — so the comparison happens once, across every medication in the house, instead of one drug and one site at a time.
